SecureText: End-to-End Encrypted Chat

A terminal chat where the server can't read the messages. 22 tests run on every push.

A chat program that runs in the terminal. I started from an intentionally insecure version and added security step by step: encrypted messages that the server can't read (ECDHA way for two people to create the same secret key over a public connection, without ever sending the key itself. + AES-GCMA fast encryption method that also detects if the scrambled message was changed on the way.), safer password storage, two-factor loginLogging in needs your password plus a second thing, like a code from an app on your phone., GitHub login, and user roles. Every push runs 22 tests, a code security check (BanditA tool that scans Python code for common security mistakes.), and my dependency scanner.
