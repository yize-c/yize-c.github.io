In one sentence

It watches the network traffic of smart home devices and raises an alarm when something looks like an attack. The goal is a good smoke alarm: one that doesn't go off every time you make toast, but also doesn't miss a real fire.

      How the real project is different

      The real project was a capstone built by a team of 6 students. It watches network traffic from smart home devices and flags attacks in two stages, using Python, PyTorch, and XGBoost. This page uses 60 made-up events and simple rules instead of trained models.

      What I learned

      • In a team of 6, keeping our Git work organized matters. I led Git integration so everyone's work came together cleanly.
      • Data quality matters as much as the model. After finding data quality problems, a teammate and I rebuilt the dataset.
      • Comparing approaches carefully (I led the comparative analysis) helped show the trade-off between missed attacks and false alarms.

      Mini glossary

      Network traffic
      The messages that devices send to each other over a network.
      Intrusion detection system (IDS)
      A system that watches traffic and raises an alert when something looks like an attack.
      False alarm (false positive)
      An alert for something that was actually harmless, like a smoke alarm going off for toast.
      Missed attack (false negative)
      A real attack that didn't raise an alert, like a smoke alarm that stays quiet during a fire.
      Threshold
      The cut-off point for raising an alert. A lower cut-off means a stricter, more sensitive system.
      Dataset
      The collection of examples used to train and test a model.
